## 📌 Mô tả dự án

Đây là một hệ thống mô phỏng tìm đường đi ngắn nhất giữa hai điểm trên bản đồ bằng các thuật toán như:

* Breadth-First Search (BFS)
* Dijkstra
* A\* (A-star)

Bản đồ được hiển thị bằng dữ liệu từ OpenStreetMap (OSM) và cho phép người dùng tương tác trực tiếp để chọn điểm bắt đầu và điểm đích.

## 🚀 Hướng dẫn chạy hệ thống

### ✅ Yêu cầu:

* Cài đặt JDK 17 hoặc mới hơn
* Cài đặt Maven
* Dùng IntelliJ IDEA hoặc VS Code (cài Java Extension Pack)

### ✅ Bước 1: Clone repo

```bash
git clone https://github.com/huyvuong1109/IT3160_Nhap_mon_AI.git
```

### ✅ Bước 2: Mở dự án

* **IntelliJ IDEA**: Chọn `File > Open` và mở thư mục dự án
* **VS Code**: Chọn `File > Open Folder`

### ✅ Bước 3: Chạy chương trình

* Mở file `AiApplication.java`
* Nhấn `Run` hoặc `Ctrl + F5`
* Console sẽ hiển thị `Tomcat started on port(s): 8080`

### ✅ Bước 4: Truy cập hệ thống

* Mở trực tiếp file `index.html` trong thư mục `html`

## ✨ Hướng phát triển tương lai

* Cho phép tìm đường đi với ràng buộc thời gian thực (tắc đường, sửa đường...)
